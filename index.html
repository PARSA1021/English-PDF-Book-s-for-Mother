📚 새로운 책 추가하는 방법

1단계: 파일 준비

추가하고 싶은 PDF 파일을 BOOK 폴더에 넣으세요.

(이미지 파일이 있다면 assets/images 폴더에 PDF와 같은 이름으로 넣어주세요.)

2단계: 목록 업데이트

폴더에 있는 '책목록업데이트.command' 파일을 더블 클릭하세요.

(검은 창이 뜨고 '성공' 메시지가 나오면 완료됩니다.)

3단계: 확인

웹사이트를 새로고침하면 새로운 책이 화면에 나타납니다!

💡 팁: 파일을 폴더에 그냥 넣기만 해도 '추가된 교재' 카테고리에 자동으로 들어갑니다.
